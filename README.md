# TTC Delay Visualization Platform

An interactive web application for visualizing Toronto Transit Commission (TTC) bus delays and live vehicle positions.

### Historical Delay Analysis (2014-2025)
- Route delays visualization
- Delay frequency analysis  
- Route comparison

### Live Bus Tracking (Simulated Demo)
- Real-time bus positions
- Delay status indicators
- Interactive bus details
